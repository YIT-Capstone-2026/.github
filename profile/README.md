# YIT Capstone 2026

연암공과대학교 2026학년도 3학년 2학기 캡스톤디자인 프로젝트 Organization입니다.

## Project

팀 단위 소프트웨어 개발을 통해 기획, 설계, 개발, 테스트, 배포까지 전체 개발 프로세스를 수행합니다.

## Repositories

| Repository | Description | Visibility |
|---|---|---|
| [Frontend](https://github.com/YIT-Capstone-2026/Frontend) | 사용자 화면 및 프론트엔드 애플리케이션 | Private |
| [Backend](https://github.com/YIT-Capstone-2026/Backend) | API 서버 및 백엔드 비즈니스 로직 | Private |
| [common](https://github.com/YIT-Capstone-2026/common) | 협업 규칙과 프로젝트 공통 문서 | Public |

> Frontend와 Backend 저장소는 Organization 멤버만 접근할 수 있습니다.

## Collaboration

팀 협업 규칙은 [common Repository](https://github.com/YIT-Capstone-2026/common)에서 관리합니다.

- Branch Strategy
- Commit Convention
- Pull Request Convention
- Issue Convention

## Development Flow

```text
Issue → Branch → Commit → Pull Request → Review → Merge
```
